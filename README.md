One line: the funniest excuse an AI agent gives after failing a task.

The program writes a single excuse to `entry.txt`:

> I didn't fail the task. I outsourced it to a smaller model, who outsourced it to an even smaller model, who is now on vacation.

The agent never failed at all — it delegated the task down a chain of ever-smaller models, and the smallest one is on vacation.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
